# Alpha FIIs - Landing Page

Landing page do produto **Alpha FIIs**, uma planilha inteligente de análise de Fundos Imobiliários.

## Sobre

Este repositório contém a página de vendas (landing page) que apresenta o produto e redireciona o visitante para a página de compra na Hotmart.

## Estrutura

```
index.html    → Landing page e sete módulos
style.css     → Layout e identidade visual
motion.css    → Animações e visualizador de imagens
app.js        → Navegação entre módulos e zoom
assets/images → Capturas reais do sistema
```

## Deploy

O site é hospedado na **Vercel**. Qualquer push na branch `main` dispara o deploy automático.

## Link de Compra

O botão de compra redireciona para o checkout do produto na Hotmart:

```
https://pay.hotmart.com/A106486647Y
```

## Desenvolvimento Local

Basta abrir o `index.html` no navegador — não há dependências de build.

## Tecnologias

- HTML5
- CSS responsivo, com suporte a movimento reduzido
- JavaScript vanilla
